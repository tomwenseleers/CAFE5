# Validation resources

For the supported model and workflow, see the [usage guide](../../innovation.md),
[mathematical specification](../../innovation_mathematics.md),
[current fit benchmark](../../innovation_benchmark.md), and
[bootstrap protocol](../../focal_bootstrap_methods.md).

The authoritative release checks and comparable-likelihood benchmark tables are
in [`../release/`](../release/). Auxiliary data in this directory are not the
release benchmark and should not be used to infer the current workflow's output
contract or select a model for another dataset.
